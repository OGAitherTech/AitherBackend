# Environment variables

| Variable | Default | Secret |
| --- | --- | --- |
| `APP_NAME` | `AitherBackend` | No |
| `APP_VERSION` | `1.0.0` | No |
| `ENVIRONMENT` | `development` | No |
| `CORS_ORIGINS` | `http://localhost:3000,http://localhost:5173` | No |

Future provider credentials, database URLs, signing secrets, and tokens should be added as secrets and must not be committed.
